# easyRecord

A simple macOS screen recorder built with SwiftUI.

Record a screen, app, or window with system audio, microphone, both, or neither. Includes live preview, 720p/1080p/4K, 30/60 fps, pause/resume, and MP4 saving.

Download the DMG from [Releases](https://github.com/roshandhiman/easyRecord/releases), open it, and drag EasyRecord to Applications.

Click the eye for live preview. If macOS asks, select the screen, app, or window in its sharing picker. Microphone access is only needed when the mic is enabled.

Requires macOS 15 or later.

Open `EasyRecord.xcodeproj` to run from Xcode. Build a DMG with `zsh scripts/build-dmg.sh`.
